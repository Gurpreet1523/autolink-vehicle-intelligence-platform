# BUG-001 — Example Defect Template

**Status:** Example / reproduce locally before claiming it as a real defect

**Title:** API latency increases under sustained telemetry load

**Environment:** Docker Compose

**Steps:**
1. Start backend and PostgreSQL.
2. Generate sustained telemetry.
3. Monitor response latency.
4. Inspect application/database metrics.

**Expected:** Latency remains within the agreed performance threshold.

**Actual:** Record the measured degradation.

**Evidence:** Attach Locust report and logs.

**Severity:** Set based on actual user impact.

**Root cause:** Determine from evidence, not assumption.

**Fix:** Document the code/configuration change.

**Regression:** Re-run API, integration and performance suites.

# Requirements

| ID | Requirement | Priority |
|---|---|---|
| REQ-001 | Registered vehicles can submit telemetry. | High |
| REQ-002 | Unknown vehicles are rejected. | High |
| REQ-003 | Battery must be 0-100. | High |
| REQ-004 | Speed must be non-negative. | High |
| REQ-005 | Motor temperature must remain in supported range. | Medium |
| REQ-006 | Vehicle status becomes ONLINE after valid telemetry. | High |
| REQ-007 | Latest telemetry can be retrieved through REST API. | High |
| REQ-008 | API exposes a health endpoint. | High |
| REQ-009 | Application can run in Docker. | High |
| REQ-010 | CI pipeline executes automated tests before deployment. | High |

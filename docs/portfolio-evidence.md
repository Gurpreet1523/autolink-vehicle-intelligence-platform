# Portfolio Evidence Checklist

Capture screenshots after running the project:

1. GitHub repository structure
2. FastAPI Swagger/OpenAPI page
3. React vehicle dashboard
4. PostgreSQL telemetry records
5. Pytest passing output
6. Coverage report
7. Locust load-test report
8. Stress-test result
9. Soak-test result
10. Failure-injection log
11. RCA document
12. GitHub Actions successful pipeline
13. Docker containers
14. Azure resource/deployment view
15. Cloud application logs/metrics

Use sanitized screenshots. Never expose credentials, tokens, customer information or proprietary company data.
